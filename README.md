# Vision-Based Physical AI & Autonomous Navigation Prototype

A full-stack Physical AI platform featuring a Python FastAPI backend that processes computer vision frames, calculates spatial coordinates, and simulates autonomous robotics commands, paired with an interactive React & Tailwind CSS dashboard.

## Running Locally with Docker Compose
Ensure Docker Desktop is running, then execute:
```powershell
docker-compose up --build
```
Access the dashboard at `http://localhost:3000`.
